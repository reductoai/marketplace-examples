# Reducto marketplace examples

Examples for Reducto models in cloud marketplaces: request and response samples, and
notebooks that deploy and call each model.

| Model | Cloud | Folder | Listing |
|---|---|---|---|
| r-1 | AWS SageMaker | [`r-1/aws-sagemaker`](r-1/aws-sagemaker) | coming soon |

Each model folder holds the input and output contract and shared samples. Each cloud
subfolder holds a self-contained example for that cloud.

Samples use synthetic pages only.
